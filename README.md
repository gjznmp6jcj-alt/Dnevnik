# Дневник похудения

Приложение: дневник питания с автоподсчётом калорий и БЖУ, тренировки, вес, прогресс.
Открывается в Telegram (мини-приложение в боте) и ставится иконкой на телефон.

Файлы: index.html (приложение), manifest.webmanifest и иконки (для установки на телефон), sw.js (работа без интернета).
Данные: в Telegram — в облаке Telegram у каждого пользователя свои; вне Telegram — в памяти телефона.
